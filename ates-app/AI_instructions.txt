AI notes from ATES QC viewer and ATES scripts session

User preferences
- Iterate quickly with small, exact visual updates instead of broad redesign.
- Keep code concise and practical, especially when simplifying copied scripts.
- Prefer direct execution and verification (run it and fix it), not only static edits.
- Keep labels and formatting exactly as requested (time/date axis details matter).
- Use Pixi tasks for normal run flow when available.

Primary scripts and ownership
- Main interactive app: ates-app/ates-app.py
- Main ATES batch script: data/ates_action_research.py
- Heating curve script: data/ates_action_select_heat_curves.py
- Keep experiment/reference scripts unless explicitly asked to remove.

Current runbook
- App run (normal): pixi run ates-app
- App run (no auto browser): pixi run ates-app-nobrowser
- App compile check: pixi run compile-check-ates-app
- Research compile check: python -m py_compile data/ates_action_research.py
- Heat-curve run: pixi run ates-curve-selection

Known workflow gotchas
- Stale process symptom: browser view does not match latest code.
- Port/process check on Windows:
  1) Get-NetTCPConnection -LocalPort 8050 -State Listen
  2) Get-CimInstance Win32_Process -Filter "ProcessId = <pid>"
  3) Stop stale Python process if needed.
- Keep one active tab when tuning layout to avoid mixed state.

Data and channel handling decisions
- data/ates_action_research.py now supports dataset switching with CONFIG_KEY_DATA_DIR:
  - data_dir_ates_afterspui
  - data_dir_ates_spui_en_afterspui
- data/ates_action_research.py supports PICKLE_DTYPE (for example float32 or float16).
- Missing channels must not crash workflow:
  - data/ahdts_channel_loader.py warns and skips missing channel folders/XML.
  - data/ates_action_research.py filters plot locations to available channels and warns.
  - If no valid filtered locations remain, summary/QC plotting is skipped with warnings.

Pump data integration lessons
- Pump Excel parsing needs tolerant matching:
  - Case-insensitive sheet matching.
  - Flexible column matching by normalized tokens.
- If pump file/columns are missing, proceed with warning and continue plotting without pump trace.

Heat-curve plotting decisions retained
- Full timeline figure is intentionally very wide and tall for manual timestamp picking.
- X-axis labels are 2-hour ticks; date appears under time at 00:00 and 12:00.
- Timeline x-range is clipped to actual data extents (no artificial empty margins).
- Pump line in full timeline is thicker and filled to 0 m3/h.

UI decisions retained in app
- Header controls and title are left-aligned for quick access.
- Heatmap and slider dimensions are increased for better readability.
- Fiber slider uses negated mapping for intuitive control with reversed y-axis.
- Heartbeat/shutdown lifecycle routes are active and request-log noise for these routes is filtered.
